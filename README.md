## 🚀 Setup rápido

```bash
cd trip-conecta-api
npm install
cp .env.example .env
# Editar .env con tus valores
npm run dev
```

Servidor local: `http://localhost:3001`

## 🧪 Verificación antes de commit

```bash
npx tsc --noEmit
```
